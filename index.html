Połączenie z Monday

Generator pobiera dane wykonawców i zakres prac przez API Monday. Token nie jest zapisany w kodzie — trzymany jest w bazie Supabase (widoczny tylko dla zalogowanych) albo, awaryjnie, w pamięci tej przeglądarki.
Jeśli wypełnione, generator w ogóle nie widzi tokena — pyta funkcję w Supabase. Puste = używa tokena poniżej.

Tablice i kolumny

Wybierz tablice, a kolumny dopasują się automatycznie po nazwach. Jeśli coś trafi nie tam, gdzie powinno — popraw ręcznie.
